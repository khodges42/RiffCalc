RiffCalc 2000 Pro (Workgroup Edition)
Voidmutt Enterprises / Department of Pattern Accounting

1. Select root, scale, genre, pattern and bars.
2. Choose Generate > New Candidate (G).
3. Press Space to audition. Escape stops.
4. Mutate (M) explores a variation. Alt+Left/Right navigates candidate history.
5. File > Export MIDI writes the selected part; Arrangement exports four tracks.
6. Drag MIDI copies the file into a compatible DAW. File export is the fallback.

View > Event Sheet inspects every note. Double-click a velocity cell to edit
that note's velocity. View > Riff Machine exposes stage locks and generation
options. Save Idea stores exact notes and settings; Open accepts legacy PACKRAT
idea files too. All ordinary file saves protect existing files.

File > Export Pack writes 8, 16, 32 or 64 related ideas and companion parts.
Choose a new directory. Failed exports retain the partial new directory.

Shortcuts: Ctrl+O open; Ctrl+Shift+S save as; Ctrl+E export; F5 use seed;
G generate; M mutate; Space play/stop; Escape stop; F1 help.

Preview is a local looping transport. Optional Host Tempo follows host BPM,
not song position. Generated MIDI leaves through files, not live MIDI output.
Workgroup Edition is product branding. No workgroup or network services exist.
